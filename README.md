# Used Cars Price Analysis

## About

This project analyzes used car prices and the factors that affect them.

The data was collected from Cars24 using Python and analyzed using Python and Power BI.

## Objectives

- Analyze price differences between car brands
- Study the effect of car age and distance driven on price
- Compare prices based on fuel type and transmission
- Identify value-for-money cars
- Study car availability by company and city

## Tools Used

- Python
- Pandas
- BeautifulSoup
- Selenium
- Power BI
- Jupyter Notebook

## Project Workflow

1. Collected used car data from Cars24
2. Cleaned and prepared the data using Python
3. Performed data analysis
4. Created Power BI dashboards
5. Identified useful patterns in used car prices

## Key Findings

### 1. Car Price Variation by Company
- Porsche has the highest average car price at around ₹52 lakhs.
- Mass-market companies such as Maruti, Tata, and Hyundai have lower average prices, making them more affordable.

### 2. Number of Used Cars by Company
- Maruti has the highest number of cars in the dataset.
- Honda, Mahindra, Renault, Ford, and KIA have comparatively lower representation.

### 3. Average Price vs Car Age
- Average car price decreases as car age increases.
- The biggest price drop is observed between 2 and 8 years of car age.

### 4. Brand-Wise Value Comparison
- Chevrolet, Fiat, and Datsun have the lowest average prices, around ₹1.4–₹1.8 lakhs.
- Maruti, Hyundai, Honda, Nissan, and Renault fall in the ₹3–₹5 lakh range.
- Premium brands have higher prices even with similar usage.
