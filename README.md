# Used Cars Price Analysis

## Overview

Analysis of used car prices to understand how company,
car age, distance driven, fuel type, and transmission
affect pricing.

## Tools & Technologies

- Python
- Pandas
- Selenium
- BeautifulSoup
- Power BI
- Jupyter Notebook

## Project Workflow

1. Web Scraping
2. Data Cleaning
3. Data Normalization
4. Exploratory Data Analysis
5. Power BI Visualization
6. Business Insights
